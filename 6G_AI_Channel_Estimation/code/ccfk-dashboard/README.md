# CCFK dashboard

Nokia CSF CCFK FreeForm dark theme UI for the 6G channel intelligence API.

```bash
cd ccfk-dashboard
npm install
npm run build    # emits to ../static/ccfk-dashboard
npm run dev      # http://localhost:5174 with API proxy to :8090
```

The operator dashboard at `/dashboard` does not require npm and is the default demo surface.
